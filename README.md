# SimpleCalendar

A lightweight Flutter Jalali calendar app.

## Features
- Persian Jalali calendar month view
- Previous and next month navigation
- Highlight the current day
- Select a day

## Build an Android APK with Codemagic
1. Sign in to Codemagic and connect your GitHub account.
2. Add the `valihk/SimpleCalendar` repository.
3. Choose the `codemagic.yaml` workflow configuration.
4. Start the **SimpleCalendar Android APK** workflow.
5. Download `app-release.apk` from the build artifacts.

The workflow generates the Android project files, resolves Flutter dependencies, runs analysis, and builds the release APK.
